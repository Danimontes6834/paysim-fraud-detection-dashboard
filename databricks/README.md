# Databricks Automation

Este directorio contiene todas las automatizaciones, notebooks y configuraciones relacionadas con Databricks.

## Estructura

- **notebooks/**: Scripts y notebooks ejecutables en Databricks
- **jobs/**: Configuraciones de Databricks Jobs
- **workflows/**: Definiciones de Databricks Workflows

## Uso

Para utilizar estos archivos en Databricks:
1. Importa los notebooks en tu workspace
2. Configura los jobs con las definiciones JSON proporcionadas
3. Ejecuta los workflows según sea necesario
